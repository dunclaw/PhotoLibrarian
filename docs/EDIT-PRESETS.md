# Edit presets and selective edits

Photo presets are stored in the user's local PhotoLibrarian settings directory. The preset catalog contains a versioned copy of the selected edit groups; photo edits themselves continue through the shared edit-recipe writer so supported formats keep embedded metadata and unsupported formats use the existing sidecar policy.

The Amount slider previews from the recipe captured when the preset panel opened, so moving it repeatedly does not compound earlier previews. Continuous values use `current + amount * (preset - current)`, with each field's supported range applied afterward: 0% is a no-op, 100% reaches the preset value, and 200% extrapolates from the photo's opening value. Discrete effects and sharpening mode, normalized crop, and retouch are transferred only at 100% or above. Retouch strokes are copied only when the target's recognized pixel identity matches the source; otherwise the group is skipped and reported. RAW-development values are skipped for raster targets. A preview or canceled panel does not write the photo or add edit history; committing a changed recipe creates one grouped undo step.

Copy, paste, and sync use the same selected-group composer and transactional edit-history path. Batch operations report skipped or unreadable photos individually; an unsupported recipe is rejected for that photo rather than silently replaced. Unknown properties in other XMP namespaces remain preserved by the shared writer. Unknown properties in the PhotoLibrarian edit namespace, unknown preset-catalog fields, and unsupported catalog versions are rejected without rewriting the existing content.

This version supports the recipe fields present in `EditParameters` on the current branch, including rotation and normalized crop. New perspective/aspect/scale/offset geometry is not interpreted here until its public complete-recipe contract is integrated; a photo carrying those unsupported edit properties is rejected rather than previewed or rewritten. Virtual-copy-family targets are not yet exposed to presets or selective sync; integration must wait for the approved public family-store contract and must continue to write only complete recipe packets.
