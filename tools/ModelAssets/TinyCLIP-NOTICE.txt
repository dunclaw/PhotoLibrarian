PhotoLibrarian extracts the vision-only pixel_values -> image_embeds graph
and recenters constant ConvInteger weights/zero points from signed INT8 to
UINT8 for CPU compatibility using an exact integer identity. Text embeddings
are generated from the pinned text graph and tokenizer for the unchanged
3,632-concept general-v2 vocabulary, using the prompt "a photo of {label}".
No training, fine-tuning or new calibration is performed for this release.
The app's existing cosine cutoffs, hierarchy, CPU-only execution and explicit
user trust requirements are unchanged. Photos and predictions remain local.
